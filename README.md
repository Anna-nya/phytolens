# PhytoLens — фронтенд ПЗ для діагностики захворювань рослин

Індивідуальний STEM-проєкт з ОК «Розробник фронтенду програмних систем».
Тема курсової роботи: «Програмне забезпечення для діагностики захворювань рослин за зображеннями з використанням методів машинного навчання».

## Можливості

- діагностика за фото листка (файл, перетягування, камера смартфона, Ctrl+V);
- вибір методу класифікації: SVM + HOG, MobileNetV2, EfficientNet-B0;
- попередня обробка в браузері: масштабування, фільтр Гаусса, вирівнювання гістограми, сегментація листка (ExG + поріг Оцу), маска уражень та оцінка площі ураження;
- пакетна обробка до 50 фото з експортом CSV/JSON;
- сторінка «Порівняння» з імпортом JSON-результатів експериментів;
- довідник 26 хвороб / 14 культур (PlantVillage, 38 класів);
- реєстрація та вхід, історія діагностик, налаштування, світла/темна тема.

Поки сервер моделі не підключено, застосунок працює в демо-режимі. Адреса сервера задається в «Налаштуваннях».

## Запуск

| Команда | Дія |
|---|---|
| `npm install` | встановлення залежностей |
| `npm run dev` | режим розробки, http://localhost:5173 |
| `npm test` | модульні тести |
| `npm run build` | збірка в `dist/` |
| `npm run preview` | перегляд збірки, http://localhost:4173 |

## API моделі

`POST /api/v1/predict` (multipart/form-data): `image`, `model` (`svm | mobilenetv2 | efficientnetb0`), `crop`, `preprocessing` (JSON).

```json
{ "predictions": [{ "class_id": "Tomato___Late_blight", "probability": 0.91 }], "inference_ms": 54 }
```

`GET /api/v1/health` → `200 OK`.

## Формат файлу результатів експериментів

```json
{
  "title": "Експеримент 1",
  "dataset": "PlantVillage, 38 класів",
  "rows": [{ "model": "svm", "pipeline": "raw", "accuracy": 0.81, "f1": 0.79, "inferenceMs": 40 }]
}
```

`model`: `svm | mobilenetv2 | efficientnetb0`; `pipeline`: `raw | denoise | denoise_eq | full`.

## Розгортання

CSP додається у збірку як `<meta>`. На вебсервері додатково задайте заголовки
`Content-Security-Policy: frame-ancestors 'none'`, `X-Content-Type-Options: nosniff`, `Strict-Transport-Security`.

| Папка | Вміст |
